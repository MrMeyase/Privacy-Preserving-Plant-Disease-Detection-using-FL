Project Description
This project presents a privacy-preserving plant disease detection system that leverages federated learning and Android-based edge AI to provide real-time crop health diagnosis while ensuring data security. The system is designed to assist farmers and agricultural workers by enabling them to identify plant diseases directly using their smartphones, without the need to upload sensitive image data to a central server.
Traditional plant disease detection systems rely on centralized machine learning approaches, where large volumes of images are collected and processed on remote servers. While effective, such methods raise concerns related to data privacy, high communication costs, and dependency on stable internet connectivity. In contrast, this project adopts a decentralized learning paradigm using federated learning, where the model is trained collaboratively across multiple devices while keeping the raw data local.
The system follows a client-server architecture. The Android application acts as the client and is responsible for capturing leaf images, performing real-time inference, and storing user data locally. A lightweight deep learning model, optimized using TensorFlow Lite, is deployed on the device to ensure fast and efficient predictions. When users choose to contribute to model improvement, the application performs local training on the device and sends only the updated model weights to the server.
The server, implemented in Python, acts as the coordination point for federated learning. It aggregates model updates received from multiple clients using the Federated Averaging (FedAvg) algorithm and generates an improved global model. This updated model is then redistributed to all participating devices, allowing the system to continuously improve over time without compromising user privacy.
A key feature of the system is its ability to operate under real-world constraints. The application includes a fallback mechanism that allows it to function even when internet connectivity is unavailable. Models are stored locally on the device, and synchronization with the server occurs only when a stable connection is available. This makes the system suitable for deployment in rural and low-connectivity environments, where traditional cloud-based solutions may fail.
In addition to privacy and efficiency, the system is designed to handle data heterogeneity, as different users may capture images under varying lighting conditions, crop types, and environmental settings. Federated learning enables the global model to learn from this diverse data distribution without requiring centralized data collection, thereby improving generalization in real-world scenarios.
Overall, this project demonstrates a practical integration of deep learning, mobile computing, and distributed learning techniques to build a scalable and privacy-aware agricultural solution. By combining real-time inference with collaborative learning, the system provides an effective tool for early disease detection while addressing key challenges related to data privacy, communication overhead, and deployment feasibility.
